# 加粗标签孤儿 `**` 修复模式

postprocess.py 的「孤儿 `**` 校正」覆盖了大量模式，但某些半角标点变体需要 Agent 在 postprocess 之后手工补检。

## postprocess 已覆盖的模式（第 3 步自动修复）

| 模式 | 修复 |
|---|---|
| `X。** 空格` | `**X。** 空格` |
| `X。**——` | `**X。**——` |
| `X。**（` | `**X。**（` |
| `第N，...XXX**`（句末整段加粗） | `第N，**XXX**` |
| 引号包裹词后跟 `**` | 补闭合 |
| 公式/计算行末尾 `**` | 整行包裹 |

## postprocess 漏掉的半角标点变体（需手工补）

以下变体中 `**` 出现在标签末尾、标点符号之前，标签**缺少开头的 `**`**，postprocess 的孤儿 `**` 规则不命中（因它主要检测行末孤立 `**` 残留，而非「缺开头 `**`」的对称情况）。

| 模式 | 修复 | 示例 |
|---|---|---|
| `XXX**：**`（半角冒号 + 全角冒号） | `**XXX**：**` | `数据图表**：**` → `**数据图表**：**` |
| `XXX**：`（仅全角冒号，无后冒号） | `**XXX**：` | `工作汇报与产品说明**：**` → `**工作汇报与产品说明**：**` |
| `XXX**：**`（后跟内容） | `**XXX**：**` | `教育解释图**：**` → `**教育解释图**：**` |

**实战来源**：2026-08-01 `开源一个非常漂亮的文章配图 Skill`，postprocess 报告「0 项需 AI」，但 4 处 `XXX**：**` 标签缺少开头 `**`，经手工修复。

## 手工修复代码

```python
import re

# 模式：行内单词后跟 **：（或 **：），无对应开头 **
# 安全做法：只在行首或段落开头的列表项中标记
patterns = [
    (r'(\S+)\*\*：', r'**\1**：'),    # 末尾 **：无换行
]
for pat, repl in patterns:
    content = re.sub(pat, repl, content)
```

注意：上述正则较粗，建议在人工通读时逐处确认，避免误匹配代码块内或已正确配对的 `**...**`。

## 操作纪律

1. postprocess 跑完后，**人工扫描所有 `：** 或 `：**` 附近的加粗标签**
2. 特别关注列表项中「标签**：**正文」的形式
3. 若发现标签缺少开头 `**`，手动补上
4. 该模式常出现在「适合的场景：/ 不适合的：」类段落中
