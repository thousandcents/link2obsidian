# 商品/服务卡片字段名参考

WeChat 产品对比、服务评测类文章常以 HTML 表格/卡片形式呈现结构化信息，HTML→Markdown 转换后退化为 `field**value` 分隔的扁平行文。

## 常见字段名集合

| 字段名 | 出现场景 | 常见值示例 |
|--------|---------|-----------|
| 项目详情 | 卡片开头标记 | （无值，仅作为节标记） |
| 免费额度 | 免费 token/额度 | 2500 万 Token、300 万 Token |
| 永久免费模型 | 免费模型列表 | GLM-5、DeepSeek-V4-Flash |
| 代表模型 | 推荐模型 | Qwen3-235B、Hunyuan-T1 |
| 注册入口 | 注册链接 | https://... |
| 覆盖模型 | 平台覆盖的模型（阿里百炼） | 通义千问全系、DeepSeek 全系 |
| API 地址 | API endpoint | https://api.qnaigc.com/v1 |
| 有效期 | 免费额度有效期 | 1 个月、1 年、活动期 |
| 推荐场景 | 适用场景 | 代码主力、白嫖首选 |

## 结构化卡片格式

多条卡片通常以 `## No.N`（或 `## No.N 🥇/🥈/🥉`）开头的节呈现。

典型结构：
```
## No.1 🥇 XXX — 标题副标题
项目详情免费额度**value1**永久免费模型**value2**代表模型**value3**注册入口**url
```

## 速览对比表格式

文末常附扁平化的速览对比表，表现为单行纯文本，无 `**` 分隔符，用排名数字/emoji 作为行分隔锚点：

```
## 📊 速览对比表排名平台免费额度有效期推荐模型适合场景🥇平台Avalue1value2value3value4🥈平台Bvalue1value2value3value4...
```

修复方式：手动重建为 GFM pipe table。
